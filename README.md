# Flask Learning Journey 🐍

This repository documents my learning journey with **Flask**, a lightweight Python web framework used to build web applications, REST APIs, and AI-powered web solutions.

## 📚 Topics Covered

### 1. Introduction to Flask
- Understanding Flask and its architecture
- Setting up a Flask application
- Creating basic web applications

### 2. Templates and Static Files
- Rendering HTML templates
- Using Flask's `render_template()`
- Serving static files such as CSS, JavaScript, and images

### 3. Application Structure
- Changing the default project structure
- Organizing Flask application files
- Understanding routes and application configuration

### 4. Handling Forms
- Creating and processing HTML forms
- Handling user input and form submissions
- Working with request data

### 5. Query Strings
- Understanding URL query parameters
- Accessing query strings using Flask
- Passing data through URLs

### 6. APIs with JSON
- Returning JSON responses
- Working with JSON data
- Building basic API endpoints

### 7. Jinja2 Templating
- Understanding Jinja2 template syntax
- Using variables, loops, and conditions in templates
- Dynamically rendering content

### 8. Template Inheritance
- Creating reusable base templates
- Using blocks and extending templates
- Reducing code duplication

### 9. Message Flashing and Redirects
- Displaying flash messages
- Redirecting users between routes
- Improving application feedback and navigation

### 10. Deploying an AI Assistant with Flask
- Integrating an AI assistant with a Flask application
- Understanding the deployment workflow
- Connecting backend functionality with an AI-powered application

## 🛠️ Tech Stack
